                              Communication Patterns
═══════════════════════════════════════════════════════════════════════════════════════════

┌─────────────────────────────────────────────────────────────────────────────────────────┐
│  1. Client-to-Gateway Communication (Synchronous HTTP)                                   │
│                                                                                           │
│     Browser ──[HTTP GET/POST]──► API Gateway                                            │
│                                                                                           │
└─────────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────────┐
│  2. Service-to-Service Communication (Feign + Eureka)                                    │
│                                                                                           │
│     API Gateway                                                                           │
│         │                                                                                 │
│         ├─[1. Query Eureka for "products-microservice"]──► Eureka Server                │
│         │                                                          │                      │
│         ◄─[2. Return: localhost:8082]────────────────────────────┘                      │
│         │                                                                                 │
│         ├─[3. HTTP Request via Feign]──────────────────► Products Service               │
│         │                                                                                 │
│         ◄─[4. JSON Response]────────────────────────────                                │
│                                                                                           │
└─────────────────────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────────────────────┐
│  3. Checkout Orchestration (Multi-Service Coordination)                                  │
│                                                                                           │
│     Checkout Service                                                                      │
│         │                                                                                 │
│         ├─[1. Get Cart Items]──────────────────► Cart Service                           │
│         ◄─[Cart Data: {asin: qty}]───────────────                                       │
│         │                                                                                 │
│         ├─[2. Validate Products]───────────────► Products Service                       │
│         ◄─[Product Metadata]──────────────────────                                       │
│         │                                                                                 │
│         ├─[3. Check Inventory]─────► YugabyteDB (product_inventory)                     │
│         │                                                                                 │
│         ├─[4. Create Order + Update Inventory]─► YugabyteDB (Transaction)               │
│         │                                                                                 │
│         ├─[5. Clear Cart]──────────────────────► Cart Service                           │
│         │                                                                                 │
│         └─[6. Return Order Confirmation]                                                 │
│                                                                                           │
└─────────────────────────────────────────────────────────────────────────────────────────┘

═══════════════════════════════════════════════════════════════════════════════════════════
                                      Notes
═══════════════════════════════════════════════════════════════════════════════════════════

1. All microservices are stateless and can be horizontally scaled
2. Eureka provides service discovery - services register on startup
3. Feign clients use service names (logical) not hardcoded URLs
4. YugabyteDB provides both SQL and NoSQL APIs in a single cluster
5. API Gateway aggregates responses to reduce client round trips
6. React UI acts as both frontend host and Backend for Frontend (BFF)
7. Current demo uses fixed user ID ("u1001") - authentication WIP
8. Checkout service orchestrates multi-service transaction flow
9. YCQL transactions enabled for orders and inventory tables
10. System designed for cloud-native deployment (Kubernetes, multi-region)
